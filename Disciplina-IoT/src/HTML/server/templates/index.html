Bem-vindo à API de Sensores!

Envie dados do NodeMCU via POST para /api/data com o JSON:

{
    "group_id": "grupo1",
    "sensor_type": "temperature",
    "value": 25.5
}

Os dados serão armazenados com timestamp automático e podem ser consultados por:

  • Grupo: GET /api/data/{group_id}
  • Visualização completa: Dashboard
